Privacy Policy for FormulaFix AI

Last updated: October 2026

1. Information We Access

FormulaFix AI requests access to Google Sheets via the spreadsheets.currentonly authorization scope. It inspects in-memory cell formulas and values strictly to perform root-cause error diagnostics in the active spreadsheet.

2. Data Processing & Storage

All formula evaluations are performed transiently in memory. FormulaFix AI does not operate an external database, does not store or log sheet contents, and never sells or transmits user data to third parties.

3. BYOK Architecture & API Keys

FormulaFix AI operates on a Bring Your Own Key (BYOK) model. User-supplied Gemini API keys are stored exclusively inside the user's private Google UserProperties sandbox and are used solely to communicate with Google's official Gemini API endpoints.

4. Limited Use Disclosure

FormulaFix AI adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Contact

For questions or support, open an issue on GitHub or reach out to the developer support contact.
